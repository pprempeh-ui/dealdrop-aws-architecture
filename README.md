# DealDrop AWS Architecture Project

This project designs a scalable AWS architecture for DealDrop,
an e-commerce platform with massive traffic spikes.

## AWS Services Used
- Amazon CloudFront
- Amazon EC2
- Auto Scaling Group
- Application Load Balancer
- Amazon ElastiCache Redis
- Amazon RDS
- Amazon Route 53

## Problem
DealDrop traffic increases from 2,000 to 60,000 users in minutes,
causing slow loading and checkout issues.

## Solution
We designed a scalable 3-tier AWS architecture using caching,
load balancing, and auto scaling.
